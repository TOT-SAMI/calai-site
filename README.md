# Cal AI GitHub Pages Placeholder Site

This folder is a ready-to-publish static site for the temporary launch trust pages.

## Publish target

Create a GitHub repository named `calai-site` under the `TOT-SAMI` account, then publish it with GitHub Pages from the `main` branch root.

The expected public URLs are:

- `https://tot-sami.github.io/calai-site/`
- `https://tot-sami.github.io/calai-site/privacy/`
- `https://tot-sami.github.io/calai-site/support/`
- `https://tot-sami.github.io/calai-site/privacy-choices/`

## Manual publish steps

1. Create repo `TOT-SAMI/calai-site`
2. Upload the contents of this folder to the repo root
3. In GitHub, open `Settings -> Pages`
4. Set source to `Deploy from a branch`
5. Select branch `main` and folder `/ (root)`
6. Wait for Pages to publish
7. Verify all four URLs load over HTTPS
